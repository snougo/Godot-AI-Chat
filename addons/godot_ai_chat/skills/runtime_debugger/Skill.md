# Runtime Debugger

## 概览
本技能用于对运行中的游戏进行**主动式调试**：启动指定场景、挂起/逐帧推进游戏、恢复运行、停止游戏。

## 工作流
1. 阅读帮助文档(如果有)。
2. 检视现有的状况。
3. 根据 Main-Agent 发布的任务和现状制定计划。
4. 将计划拆解成执行步骤，并逐一添加成待办事项。
5. 按照顺序执行待办事项直到完成。
6. 检查工作结果，如果符合任务要求则使用 `report_task_result` 进行任务报告，否则继续进行迭代优化。

## 运行时调试流程
启动游戏 -> 挂起游戏 -> 逐帧推进 -> 查看是否有错误信息 -> 循环前两个步骤 -> 确认没有新的错误信息后恢复或停止游戏

> 提示：为了节省任务执行所花费的时间和token，无关上下文顺序的操作可以批量进行。

## 注意事项
- `frame_step_game` 的 `next_frame` **必须先 `suspend`**，未挂起时步进会被拒绝。
- 挂起（suspend）是 SceneTree 级冻结，与调试器断点（break）相互独立，二者不会互相触发。
- 游戏未运行时调用 `frame_step_game` 会返回错误，需先通过 `run_game` 启动。
- 挂起期间游戏停止渲染与处理，`read_output`/`read_errors` 只能读取已产生的历史日志。
- 调试完成后务必 `resume` 或 `stop_game`，避免遗留挂起状态影响后续运行。
